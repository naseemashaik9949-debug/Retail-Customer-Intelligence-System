# Retail & Customer Intelligence System

## 📌 Project Overview

The Retail & Customer Intelligence System is an end-to-end retail analytics project developed to analyze sales performance, profitability, customer behavior, product performance, discounts, and regional trends.

The project uses Oracle SQL, Python, Excel, and Power BI to transform raw retail transaction data into actionable business insights and an interactive analytical dashboard.

---

## 🎯 Project Objectives

- Analyze overall sales and profitability performance.
- Identify high-value and loss-making customers.
- Evaluate product and sub-category profitability.
- Analyze the relationship between discounts and profit.
- Compare regional and segment-level performance.
- Identify sales and profit trends over time.
- Build an interactive Power BI dashboard for business analysis.
- Apply data extraction, transformation, loading, validation, and data quality concepts.

---

## 🛠️ Tools & Technologies

- **Oracle SQL** – Data querying, aggregation, KPI analysis, CTEs, views, and window functions
- **Python** – Pandas, exploratory data analysis, customer segmentation, and visualization
- **Excel** – PivotTables, analysis, and reporting
- **Power BI** – Data modeling, DAX, interactive dashboards, slicers, bookmarks, tooltips, Smart Narrative, Decomposition Tree, and Key Influencers
